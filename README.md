# TrikoPatron ERP Sistemi 🧶

**Tekstil sektörü için uçtan uca üretim, stok ve finans yönetim çözümü.**

Doğuş Üniversitesi Yönetim Bilişim Sistemleri (YBS) kapsamında geliştirdiğim bu proje, tekstil atölyelerindeki karmaşık iş süreçlerini dijitalleştirerek verimliliği artırmayı hedeflemektedir.

## 🚀 Öne Çıkan Özellikler

* **Üretim Takibi:** İplik girişinden sevkiyat aşamasına kadar tüm süreçlerin anlık kontrolü.
* **Finans Yönetimi:** Giderlerin ve tahsilatların detaylı raporlanması.
* **Raporlama:** Haftalık ve aylık üretim metriklerinin analizi.

## 🛠️ Kullanılan Teknolojiler

* **Dil:** Python
* **Arayüz:** Flask / HTML Templates
* **Veritabanı:** SQL

## 💡 Neden TrikoPatron?

Bu sistem, manuel takip sistemlerindeki veri kaybı ve karmaşayı önlemek amacıyla "yönetici vizyonuyla" kurgulanmış bir mühendislik çözümüdür.
